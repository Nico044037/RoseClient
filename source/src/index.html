Client-side only

RoseClient installs as a client-only Fabric mod. No server companion is included or required for its local HUD and visual modules. A rose marker identifying other RoseClient users cannot be verified from the client alone, so that feature is not included.

♢
Account security

RoseClient encrypts saved authentication data with OS-backed secure storage. It never saves your Microsoft password. Use Log out to remove the saved login.
