# RoseClient in-game Fabric mod scaffold

Targets Minecraft 26.1.2 and Java 25. This project is a starter scaffold: it shows an in-game RoseClient HUD marker and a basic Right Shift menu overlay. It is not yet the full set of client modules, rainbow nametag renderer, item physics, or FPS optimization features.

Fabric APIs and mappings change between Minecraft versions; if the build fails, update the Loom/loader dependencies to the current compatible versions and follow the official Fabric 26.1 migration guide.
